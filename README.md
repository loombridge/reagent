# Reagent

Reagent is an open-source wavetable synthesiser written in Rust, for macOS (Apple Silicon), Windows and Linux. It runs inside Beatlayer as a native instrument, as a CLAP, VST3 and Audio Unit plug-in in other hosts, as a standalone app, and headless from the command line, and every action a person can take in it, an agent can take too. It is built on the [plug-in kit](https://github.com/loombridge/plugin-kit) and is in early development. Licensed under [GPL-3.0-or-later](LICENSE).
